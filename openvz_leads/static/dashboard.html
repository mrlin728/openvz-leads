What is OpenVZ Leads?

OpenVZ Leads is an autonomous AI sales agent. Once set up, OpenVZ Leads runs on its own: finds people who match your ideal customer, writes personalized cold emails, sends them through your email platform, reads every reply, handles objections, and works toward booking a meeting. You review everything through this dashboard.

OpenVZ Leads runs on your Claude Max subscription, so there are no extra AI costs. Everything stays on your machine in one folder.

Getting Started

There are three things to do:

1. Teach it your product — `openvz-leads train <your-url>`, or ask Claude
2. Say who you are after — the Target tab, or `openvz-leads target "..."`
3. Go to the Controls tab and click Start

The Setup tab shows you exactly what's done and what still needs to happen.

Getting Your API Keys

Instantly API Key (optional)

Instantly is one of the two ways OpenVZ Leads can send — the other is your own Gmail. You need neither to start: with no provider configured the whole pipeline runs, the drafts land in the review queue, and you take them out from the Export tab.

If you do want it to send through Instantly:

1. Sign up at instantly.ai (API access is on their Growth plan)

2. Go to Settings > Integrations

3. Copy your API key

4. Paste it in the Settings tab here

LinkedIn Credentials (optional)

If you want OpenVZ Leads to find prospects on LinkedIn, enter your LinkedIn email and password. OpenVZ Leads uses a real browser to search LinkedIn like a human would, with random delays and rate limits to avoid detection.

If you skip this, OpenVZ Leads will find prospects through Google searches and company website scraping instead.

Cloudflare Browser Rendering (optional)

This is only used during product training (when OpenVZ Leads crawls your website to learn about your product). It handles JavaScript-heavy websites that a basic crawler can't read.

1. Sign up at Cloudflare (paid Workers plan, ~$5/month)

2. Go to Workers & Pages > Browser Rendering

3. Create an API token with Browser Rendering Edit permissions

4. Enter your Account ID and API Token in the Settings tab

Without this, OpenVZ Leads uses a built-in crawler that works fine for most websites but can't render JavaScript.

Common Issues

"command not found: openvz-leads"
You need to activate the virtual environment first: source .venv/bin/activate
Instantly API returns 401
Your API key is wrong, or you need the Growth plan (the free plan doesn't include API access). Double-check the key in Settings > Integrations in your Instantly dashboard.
Claude headless mode fails
Make sure you've run claude login in your terminal and have an active Claude Max subscription. OpenVZ Leads uses your existing subscription, not a separate API key.
OpenVZ Leads isn't finding prospects
Check that your ICP (ideal customer profile) in openvz-leads.yaml has realistic titles, industries, and geography. If LinkedIn is set up, check that the credentials are correct. Check the Activity tab to see what OpenVZ Leads has been trying to do.
